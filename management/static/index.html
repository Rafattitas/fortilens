        05

        Choose what to collect

        Existing collectors and accounting behavior are reused.

        WAN, SLA and interface options share one exporter. Its collector stops only when all three are off. Existing Grafana dashboards remain intact.

        Host mode requires native UDP and a FortiGate IPv4 address. It reserves the same TCP port on loopback for Alloy and the next TCP port for private health. No rsyslog installation is required.

        Use the device serial or traffic-log devid, not an administrator username. Leave unbound only after reviewing data quality.

        Optional exporter capabilities

        Omit only individually verified unsupported capabilities. Required interface, device and SLA probes remain enabled. Unchanged selections preserve the existing profile; unchecking restores only these capabilities. Custom probe rules stay intact.

        VDOM, accounting timezone and device identity are locked once an accounting source contract exists. They require a separate migration.

        06

        Storage & data retention

        Policy changes never resize a disk or restore missing records.

        Insufficient data for storage estimation

        Reducing existing retention/size ceilings requires an explicit data-preservation procedure. Raising retention does not guarantee that storage is sufficient.
